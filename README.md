# SIPWI Travel Planner

Aplikasi travel planner premium berbasis HTML/CSS/JS.

## Cara Pakai di VS Code

### 1. Buka di VS Code
```bash
code sipwi-project
```

### 2. Install Live Server (extension VS Code)
- Buka Extensions (Ctrl+Shift+X)
- Cari **"Live Server"** by Ritwick Dey
- Klik Install

### 3. Jalankan
- Klik kanan pada `index.html`
- Pilih **"Open with Live Server"**
- Browser otomatis terbuka di `http://127.0.0.1:5500`

---

## Struktur File

```
sipwi-project/

```

## Navigasi Fitur
- **Beranda** — Home dashboard
- **Planner** — Quiz 3 tahap untuk planning trip
- **Trip** — Hasil itinerary + rekomendasi
- **Schedule** — Jadwal harian + Google Calendar + Invite team
- **Profil** — Profil user + settings
